# STM32F103xx Low-Level Device Drivers Library

A low-level device driver library for the STM32F103xx ARM Cortex-M3 microcontroller and its peripherals. This library provides bare-metal access to essential MCU hardware features and is designed for embedded developers seeking full control over the STM32F1 series hardware without relying on high-level HAL/LL libraries.

## 📌 Overview

This library offers:
- Direct register-level access to STM32F103xx microcontroller peripherals.
- Modular driver architecture for easy customization and extension.
- Minimal abstraction to maximize performance and code size efficiency.

While tailored for the STM32F103xx series, most drivers are compatible with other STM32F1 family microcontrollers with little or no modification.

## 🧩 Supported Peripherals

The library includes drivers for:
- GPIO (General Purpose I/O) - Under Construction
- RCC (Reset and Clock Control)
